# TypeScript OpenAI Chatbot

Shows how to add model chat to a public page without putting API keys in the browser. The page sends messages to your `/api/chat` endpoint, the server calls the room's OpenAI-compatible proxy, and MeshAgent keeps the sensitive model connection on the server side.

## Next Steps

1. Run locally:

   ```bash
   npm run dev
   ```

2. Deploy:

   ```bash
   npm run deploy
   ```
